# LinkNinja

## Link Intelligence and Analytics Dashboard

LinkNinja is a simple web-based analytics dashboard built using **HTML, CSS, and JavaScript**.

The project demonstrates how a link analytics platform can display link activity, traffic information, and basic fraud-risk insights through a dashboard interface.

## Features

* Link analysis interface
* Traffic statistics
* Human and bot traffic data
* Traffic analytics
* Fraud-risk indicator
* Dashboard navigation
* User profile and settings
* Dark brutalist-style dashboard

## Technologies

* HTML5
* CSS3
* JavaScript
